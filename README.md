# 📋 appDenunciasApi

> API REST para la gestión de denuncias.

## ⚙️ Tecnologías

| Tecnología | Detalle |
|---|---|
| ☕ Java | 21 |
| 🍃 Spring Boot | 3.4.5 |
| 🗄️ Spring Data JPA | ORM / persistencia |
| 🐘 PostgreSQL | Producción |
| 💾 H2 | Memoria (local por defecto) |

## 🚀 Ejecutar

```bash
./gradlew bootRun
```

Servidor en `http://localhost:8080`
